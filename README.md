# Haven Housing landing page

Static website for GitHub Pages.

## Publish
1. Create a public GitHub repository such as `haven-housing-site`.
2. Upload all files from this folder to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, branch `main`, folder `/(root)`.
5. Save.
6. Set the custom domain to `havenhomes.school`.
7. After DNS and TLS are ready, enable Enforce HTTPS.
