# Haven Home landing page

Static website for GitHub Pages.

## Publish
1. Use the `main` branch and repository root for GitHub Pages.
2. Set the custom domain to `havenhome.life`.
3. Point the domain's GitHub Pages DNS records at GitHub.
4. After DNS validation and certificate issuance complete, enable Enforce HTTPS.
5. Keep `havenhomes.school` active during migration until the new domain is verified.
